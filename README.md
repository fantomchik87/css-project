# CSS Final Project

Responsive one-page layout based on the Figma prototype. The project uses semantic HTML, BEM naming, Sass partials, desktop/mobile media queries, animations, Stylelint, Prettier, PostCSS, Autoprefixer and cssnano.

## Commands

```bash
npm install
npm run build
npm run prod
npm run lint
npm run format
```

Open `src/index.html` with Live Server.
